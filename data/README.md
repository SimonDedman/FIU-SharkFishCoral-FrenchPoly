# Data archive

The data underlying this analysis are deposited on the **FIU Dataverse** at:

> **DOI: TBD** (assigned on deposit) - https://dataverse.fiu.edu/dataset.xhtml?persistentId=doi:TBD

Please cite the data archive separately from the article and the code archive. The article reports the analysis; the Dataverse archive holds the data; the GitHub/Zenodo archive holds the code.

This `data/` directory in the GitHub repository is intentionally empty of data files. The full archive lives on Dataverse. The repository's R scripts read from local copies under `NFF_data/` (gitignored); see "Reproduction" below for how to download and place the Dataverse contents.

### Fitted Bayesian models (Tier 1 reproducibility)

The full Bayesian fit takes a substantial amount of time on typical hardware (44 brm fits across 4 scenarios, with `add_criterion(loo, reloo = TRUE)` triggering refits where Pareto-k diagnostics are poor). Reviewers can skip that step by downloading these files and `readRDS()`-ing them. The compiled Stan binaries have been stripped (`R/utils/strip_brm_dso.R`) to reduce file size; re-sampling will require a one-time recompile, but `summary()`, `plot()`, `posterior_predict()`, and `loo()` work directly.

| File | Description | Size |
|---|---|---|
| `models_list_Atolls_BottomUp_spline.Rds` | List of 11 fitted brm models for Atoll bottom-up scenario. | ~19 MB |
| `models_list_Atolls_TopDown_spline.Rds` | Atoll top-down scenario. | ~17 MB |
| `models_list_HighIslands_BottomUp_spline.Rds` | High-islands bottom-up scenario. | ~20 MB |
| `models_list_HighIslands_TopDown_spline.Rds` | High-islands top-down scenario. | ~17 MB |
| `posteriors_list_spline.Rds` | Pooled posterior_epred draws. | ~15 MB |

## Reproduction

To run the full pipeline locally:

1. Clone this repository: `git clone https://github.com/SimonDedman/FIU-SharkFishCoral-FrenchPoly.git`
2. Download the Dataverse archive to `NFF_data/` at the project root.
3. Open the project in RStudio (`FIU-SharkFishCoral-FrenchPoly.Rproj`) and run `renv::restore()` to install pinned package versions.
4. Run scripts in numeric order; or use `targets::tar_make()` to run the full pipeline (see top-level README for details).

For Tier 1 reproducibility (skip Bayesian fit), download only the `models_list_*_spline.Rds` files and `posteriors_list_spline.Rds` from the Dataverse archive into `Results/DAG/`, then run scripts 06-08 only. Loading the model lists and producing all summary plots takes a few minutes on typical hardware.
